# 信息源优先级规范

> 用于「每天介绍一个国际竞赛」系列视频的事实核查。
> 每期视频在写文案（第二步）前，所有数据都要按本规范确定来源与可信度。

---

## 核心原则：先分事实类型，再选来源

竞赛信息有两个独立属性，**不能压成一个优先级清单**：

| 属性 | 含义 | 谁强 |
|------|------|------|
| **权威性** | 来源可不可信 | IMA 笔记 / 赛事官网 |
| **时效性** | 是不是当季信息 | 赛事官网 / 实时搜索 |

IMA 笔记是「权威但可能过期」，官网是「权威且当季」。所以**同一条优先级不能套到所有字段上**——要先判断这条事实是「恒定」还是「易变」，再选对应的来源顺序。

---

## 第一步：判断事实类型

### 恒定事实（很少变，IMA 笔记基本可信）
- 创办人、创办年份、主办机构
- 赛事性质与定位（如「国际唯一经济学奥赛」）
- 历史沿革
- 知识领域大类
- 对升学/申请的价值与意义

### 易变事实（逐年变，必须当季官网为准）⚠️
- 报名截止日 / 各轮比赛日期
- 主办城市、地点
- 报名费
- 题量、题型、考试时长
- 年龄 / 年级 / 资格线
- 获奖比例、晋级线
- 当年成绩（如「某年某队几金几银」）

> 维护一份「易变字段清单」，命中清单的事实自动触发**时效闸门**（见下）。

---

## 第二步：按类型选来源优先级

### 恒定事实
```
IMA 笔记  >  IMA 知识库  >  赛事官网  >  互联网搜索
```

### 易变事实
```
当季赛事官网  >  当季互联网一手源  >  IMA 笔记（仅当带当季日期戳）
```
> 易变事实里 IMA 笔记**降级**，且必须过时效闸门。

---

## 来源内部再分层

「官网」和「互联网」都不是铁板一块，各自再细分：

**赛事官网层（高→低）**
1. 官方全球主体（如 `ieo-official.org`、`files.ieo-official.org` 的监管 PDF）
2. 官方国家 / 区域主体（如 IEO 中国区官方）
3. 授权合作方
4. 中介 / 代理页（**不算官方**，仅作旁证）

**互联网层（高→低）**
1. 官方文档 / 一手来源
2. 维基百科 / 权威教育机构站点
3. 中介 / 论坛 / 自媒体（仅作旁证，不能单独支撑事实）

> ⚠️ **按来源主体分层，不按检索渠道分层**：从搜索引擎翻到的官方 PDF，本质是「官网层」，不因为「是搜来的」而降级。

---

## 跨类铁律（适用于所有事实）

1. **时效闸门（最重要）**
   凡属易变字段，IMA 笔记 / 知识库只能当**草稿和默认值**，发布前**必须**用当季官网复核：
   - 官网确认 → 采用
   - 官网冲突 → **官网赢** + 标记 + **回写更新 IMA 笔记**（让知识库越用越准）
   - 恒定字段不走这道闸

2. **全字段打日期戳**
   每条事实记录 `(来源, 赛季年份, 抓取日期)`。**无日期 = 视为未核实**，不得直接进视频。

3. **优先级挂在原始出处上，不挂在「整理稿」上**
   「检索整理 / 搜索整理」里的"整理"是二次加工，可能丢上下文甚至失真。必须保留原文引用 + URL + 日期；整理稿只是派生视图，可信度继承自它忠实引用的原始出处。

4. **冲突裁决**
   - 易变事实：IMA 与官网冲突 → 官网赢
   - 恒定事实：IMA 与官网冲突 → 以 IMA 为框架，但用官网交叉验证后定稿
   - 两个一手源互相矛盾 → 标记「待核实」，人工裁决，不擅自二选一

5. **两源印证**
   仅存在于低档互联网（中介 / 论坛 / 自媒体）的事实，需要第二个独立来源印证，否则在视频里标「待核实」或直接省略。

6. **兜底**
   四档全查不到 → **留空或标注「待核实」，绝不用模型记忆补**。
   官网没提及 ≠ 不存在，不要反推「无」。

---

## 每期视频核查清单

写文案前对照执行：

- [ ] 列出本期所有要用到的数据点
- [ ] 每个数据点标注：恒定 / 易变
- [ ] 易变数据点 → 全部用当季官网复核，记录 URL + 日期
- [ ] 区分赛事的全球站 vs 国家/区域站（格式可能不同，别混用）
- [ ] 中介页的说法 → 一律找官方一手源印证
- [ ] 每条事实都有 `(来源, 赛季, 抓取日期)`
- [ ] 复核中发现 IMA 笔记过期的 → 回写更新
- [ ] 查不到的 → 标「待核实」或省略，不靠记忆补
